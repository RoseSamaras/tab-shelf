Ollama

If Ollama still blocks the extension

Tab Shelf normally handles this for you. If requests are still blocked, allow extensions in Ollama directly. Quit Ollama completely, then:

macOS:   launchctl setenv OLLAMA_ORIGINS "chrome-extension://*"   (then reopen Ollama)
Linux:   OLLAMA_ORIGINS="chrome-extension://*" ollama serve
Windows: setx OLLAMA_ORIGINS "chrome-extension://*"   (then restart Ollama)

Then download a model, for example ollama pull llama3.1:8b. Any small instruct model works.
